学习空间

这里整理我在 Agent 系统里反复遇到、但还没有形成定论的问题。每条都来自真实代码、issue 或失败案例；等结论稳定后，再补上完整笔记。

Agent Runtime

阅读流式协议、会话与目标生命周期、调度恢复和可观测性的实现。

尚未解决的问题：流式输出在任意 chunk 边界被截断时，解析、持久化和前端呈现如何保持一致？

Sandbox Security

关注密钥生命周期、租户隔离、出口策略，以及不可信代码执行时的最小权限边界。

最近的疑问是：多语言 SDK 的重试语义如何区分幂等与非幂等操作，而不把一次失败扩散成额外副作用？

Cross-platform Engineering

整理 Windows 与 WSL 上的路径、编码、进程模型和 CI 验证差异。

下一步实验：怎样让只在原生 Windows 出现的问题稳定进入自动化测试，而不是依赖人工复现？
