GoldMind

黄金市场分析平台

基于 LangChain Multi-Agent 的黄金市场分析平台。它把行情、新闻、机构观点和量化因子汇合到一个可追溯的看板里；数据过期或不可用时明确标出，不用模型猜测填空。

Python、Vue 3、LangChain；MIT 许可；当前公开版本 v2.0.3。

GitHub 仓库 Release v2.0.3

LikeCodex

开源 AI 编程助手

面向 DeepSeek 的 AI 编程助手，按 Rust、Python、TypeScript 分层：Rust 负责桥接、SSE 与沙箱执行，Python 驱动 Agent 循环，Next.js 提供 Web UI。项目包含审批策略、Shell 风险分类、Docker 隔离和文件检查点。

Rust、Python、TypeScript；MIT 许可；已发布到 PyPI，包名为 likecodex。

GitHub 仓库 PyPI

编程代理工作规约

AGENTS.md；Codex、Claude Code；中英双语；MIT 许可。
